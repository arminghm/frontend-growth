# Frontend Interview Review Notes

These notes consolidate the frontend interview-preparation material discussed in this conversation. They are written entirely in English for clean Markdown rendering and future review.

## How to review

Use active recall rather than passive rereading:

1. Read only the title and section headings.
2. Explain the topic from memory.
3. Answer the review questions without looking.
4. Re-read only the weak sections.
5. Re-test later without hints.

Understanding an explanation is not the same as mastery. Stronger interview evidence comes from independent answers, debugging, implementation, trade-off reasoning, and design decisions.
