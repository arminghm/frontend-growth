# Frontend Growth

Persistent evidence-based roadmap for advancing Senior Frontend Engineering skills.

## Repository purpose

This repository tracks:

- what is already strong,
- what is still developing,
- concrete evidence behind assessments,
- current learning priorities,
- future verification targets,
- progress over time.

It is not a notebook of everything studied. Learning material can live in ChatGPT conversations; this repository records durable conclusions and evidence.

## Start here

1. `CURRENT.md` — what to work on next.
2. `STATUS.md` — current high-level assessment.
3. `ROADMAP.md` — ordered progression plan.
4. `maps/frontend.md` — one-glance skill map.
5. `skills/` — domain-specific assessments.
6. `evidence/` — dated evidence supporting changes.

## Working model

- ChatGPT Project: tutoring, reasoning, mock interviews, assessment.
- This repository: persistent source of truth.
- Codex: useful when repository work becomes executable/code-heavy.

See `AGENTS.md` for update rules.
